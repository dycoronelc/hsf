# Ajustes Solicitados

A continuación, se detallan los ajustes solicitados al proveedor INNEXIA sobre el módulo de gestión de tickets (Consola Staff / Cola de Espera), con el fin de optimizar la operación diaria de los Oficiales de Admisión:

| **Ajuste Solicitado**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1\. Mantener seleccionado el Destino de Llamado**<br><br>Al llamar un ticket, el Destino del Llamado (ventanilla) debe mantenerse seleccionado. Actualmente el Oficial de Admisión debe volver a seleccionarlo cada vez que llama un ticket, lo cual genera pasos repetitivos innecesarios.                                                                                                                                                                                                                                                                                                                                                                                    |
| **2\. Visibilidad exclusiva del ticket para la ventanilla que lo llamó**<br><br>Al llamar un ticket, este debe mostrarse únicamente en la ventanilla que realizó el llamado. Esto evita que otros Oficiales de Admisión puedan iniciar la atención o finalizar el ticket por error.                                                                                                                                                                                                                                                                                                                                                                                              |
| **3\. Mostrar tiempo de espera en la Cola de Espera**<br><br>En la lista de Cola de Espera, se solicita agregar un campo que muestre el tiempo transcurrido desde que el ticket ingresó a la cola. Puede ser actualizado cada minuto.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **4\. Ordenar la Cola de Espera por orden de llegada**<br><br>El orden de la lista de Cola de Espera debe respetar el orden de llegada de los tickets. Sugerencia: Contador secuencial por tipo de ticket, iniciando desde 001.<br><br>Ejemplo: **T-001**, **T-002**, etc. --- **OT-001**, **OT-002**, etc.<br><br>Esto controla el orden de llamado, así como también ayuda a pacientes conocer su próximo turno.                                                                                                                                                                                                                                                               |
| **5\. Eliminar la Cola de Transferidos**<br><br>Se solicita eliminar la Cola de Transferidos como lista independiente e integrar estos tickets dentro de la Cola de Espera general. Justificación: es más eficiente que todos los tickets pendientes por llamar se encuentren consolidados en una sola lista.                                                                                                                                                                                                                                                                                                                                                                    |
| **6\. Monitor – Pantalla de Llamados**<br><br>a. Aumentar tamaño de fuente del texto **TURNO**.<br><br>b. Extender el texto "Ventanilla #" más ancho para mejor visualización de adultos mayores.x. Que ocupe todo el ancho de esa columna.<br><br>c. Extender y aumentar un poco más el texto "Bienvenido al Hospital Santa Fe, por favor estar atento a su turno." Que aparece como pie de página del monitor.<br><br>d. Tickets llamados parpadeando mientras se llama: **OK**.<br><br>Luego de llamado e iniciar Atención mostrar en monitor **en atención** sin parpadear y mantenerse en pantalla. Nos muestra junto con el cambio del punto 4 a conocer el próximo turno. |
| **7\. Triage & Consulta**<br><br>Se solicita unificar bajo Tipo de Servicio Triage los Tipos de Tickets **Triage** y **Consulta**.<br><br>Sobre el flujo de Atención, estos Tipos de Tickets se atienden en Área de Triage, siguiendo las prioridades Triage **1**, Consulta **2** (Medicina General). De esta manera la pantalla Cola de Espera sobre el Tipo de Servicio Triage mostrará ambos tipos de Tickets para ser llamados en Destino del llamado: Triage.                                                                                                                                                                                                              |
